TITANFIT Gym Website - Complete Backend API Documentation
This is the official REST API documentation for the TITANFIT Gym Management Application backend. Built with Node.js, Express.js, JWT (JSON Web Tokens), and MongoDB (Mongoose).

🚀 Base URL
Plaintext
http://localhost:5000/api
📋 Endpoints Overview
Method	Endpoint	Description	Auth Required
GET	/	Health check endpoint	❌ No
POST	/api/auth/register	Register a new member account	❌ No
POST	/api/auth/login	Authenticate user & receive JWT	❌ No
GET	/api/auth/profile	Get current logged-in user profile	🔒 Yes (Bearer Token)
PUT	/api/auth/profile	Update member metrics (weight/height/goal)	🔒 Yes (Bearer Token)
POST	/api/bookings	Book a trial or membership session	❌ No
GET	/api/bookings	Fetch all bookings (Admin view)	❌ No
PUT	/api/bookings/:id	Update booking status or add admin note	❌ No
POST	/api/contact	Submit a contact query / message	❌ No
GET	/api/contact	Fetch all contact messages (Admin view)	❌ No
PUT	/api/contact/:id	Reply to a contact message	❌ No

2. Authentication & User Profile APIs (/api/auth)
🔹 Register New Member
Creates a new member account and returns a JWT token.

URL: /api/auth/register

Method: POST

Headers: Content-Type: application/json

Request Body:

JSON
{
  "name": "Rahul Sharma",
  "email": "rahul@example.com",
  "password": "password123",
  "fitnessGoal": "Muscle Gain",
  "weightKg": 72,
  "heightCm": 178
}
Success Response (201 Created):

JSON
{
  "success": true,
  "message": "Registration successful!",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "66a3ef89021b1a45c2f812a1",
    "name": "Rahul Sharma",
    "email": "rahul@example.com",
    "role": "member",
    "activePlan": "Free Trial",
    "enrolledProgram": "General Fitness"
  }
}

🔹 Get Logged-in User Profile
Fetches current user's profile details and fitness measurements.

URL: /api/auth/profile

Method: GET

Headers:

HTTP
Authorization: Bearer <YOUR_JWT_TOKEN>
Success Response (200 OK):

JSON
{
  "success": true,
  "data": {
    "_id": "66a3ef89021b1a45c2f812a1",
    "name": "Rahul Sharma",
    "email": "rahul@example.com",
    "role": "member",
    "activePlan": "Pro Athlete",
    "enrolledProgram": "Strength & Power",
    "assignedTrainer": "Marcus Vance",
    "weightKg": 72,
    "heightCm": 178,
    "fitnessGoal": "Muscle Gain",
    "createdAt": "2026-07-25T11:56:00.000Z"
  }
}
